Setup

Five steps, about 10 minutes. Everything is saved automatically.

  1. 1Game mode

  2. 2Connect Dota 2

    Dota sends live game data to this app through Game State Integration. It needs one small config file in your Dota folder.

    Download file

    Manual: put the file in …\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\ (create the folder). Then add -gamestateintegration to Dota's launch options in Steam and restart Dota. Spectate or watch a replay – the light turns green.

  3. 3Streaming app

    OBS: Tools → WebSocket Server Settings → Enable, copy the password.

    Streamlabs: Settings → Remote Control → click the QR code area → “Show details”, copy the API token. Experimental – please report issues.

    Without a connection everything still works – you switch scenes and save replays with your own hotkeys; the overlays react on their own.

  4. 4Replay buffer

    Turn on the replay buffer (OBS: Settings → Output → Replay Buffer; Streamlabs: Settings → Output → Replay Buffer) and set the recording format to MP4 – browsers can't play MKV.

  5. 5Add the overlays

    Add each page as a Browser Source, width 1920, height 1080, in its own scene. Tick “Control audio via OBS” if you want clip sound (and add ?sound=1).

Hotkeys & Stream Deck

Every button in this panel is also a URL. Use them from a Stream Deck (“Website” action with “GET request in background”, or Bitfocus Companion's HTTP GET), AutoHotkey, Touch Portal, or a terminal (curl).
